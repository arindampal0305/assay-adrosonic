HOW IT WORKS

A 4-Agent Pipeline, Built for Accuracy

ASSAY uses LangGraph to orchestrate 4 specialized AI agents, with human approval at the center and deterministic code for every change.

1

Sheet Intelligence

Finds the right sheet, header and structure.

2

Schema Mapping

Maps to 17 target fields using 3-channel scoring + global solver.

3

Data Quality & Reasoning

Detects issues and proposes fixes with plain-English rationale.

4

Human Review

You approve, edit or reject with full context and before/after view.

5

Controlled Transformation

Runs approved changes via deterministic code and creates audit logs.
